# Календарь дивидендов российских акций

Собирает календарь дивидендных выплат по заданному списку акций MOEX и
публикует его как статическую HTML-страницу и CSV-файл. Обновляется
автоматически раз в сутки через GitHub Actions.

Живая страница (после настройки Pages): `docs/index.html`, публикуется на
`https://<username>.github.io/<repo>/`.

## Откуда данные

- **MOEX ISS** (`iss.moex.com`, открытый API, ключ не нужен) — текущая цена
  и короткое название бумаги.
- **[smart-lab.ru/dividends](https://smart-lab.ru/dividends/)** — размер
  дивиденда на акцию и дата закрытия реестра.

  MOEX ISS действительно отдаёт дивиденды по конкретной бумаге, но только
  подписчикам платного Corporate Information Service — открытого
  бесплатного эндпоинта для этого на данный момент нет. Смарт-лаб — самый
  полный публичный источник с этими данными, поэтому используем его.
  Обратная сторона: это не официальный API, а разбор HTML-таблицы, вёрстка
  сайта может со временем измениться и сломать парсер (`src/smartlab.py`).

Дата "купить до" (T-1) считается в коде (`src/model.py`) как предыдущий
**будний** день перед закрытием реестра. Это упрощение: реальный
торговый календарь МосБиржи с праздниками не учитывается, поэтому в
редких случаях (если перед закрытием реестра будний день оказывается
биржевым праздником) дата может отличаться от фактической на 1 день.

## Установка и запуск локально

Нужен Python 3.11+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```

Результат появится в `docs/index.html` и `docs/dividends.csv`.

## Как добавить свой тикер

Откройте [config.yaml](config.yaml) и добавьте код бумаги в список
`tickers` — он должен совпадать с колонкой "Тикер" на
[smart-lab.ru/dividends](https://smart-lab.ru/dividends/) (обычно это и
есть код MOEX, например `SBER`, `GAZP`, `LKOH`). Затем запустите скрипт
ещё раз — он подтянет данные, если для этого тикера они есть на
smart-lab.ru.

Если по тикеру нет ни цены с MOEX, ни строки на smart-lab.ru — он просто
не попадёт в итоговую таблицу (в логах будет предупреждение), остальные
тикеры при этом всё равно соберутся.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest
```

`tests/test_parsing.py` проверяет разбор HTML-таблицы дивидендов на
заранее подготовленном примере (без обращения к сети).
`tests/test_yield.py` проверяет расчёт T-1 и дивидендной доходности.

## Автообновление (GitHub Actions + Pages)

`.github/workflows/update.yml` раз в сутки по расписанию (cron, 06:00
UTC / 09:00 МСК) запускает скрипт и коммитит обновлённые
`docs/index.html` и `docs/dividends.csv` обратно в ветку `main`, если
данные изменились. GitHub Pages настроен отдавать сайт из `main` →
`/docs`.

Запустить обновление вручную, не дожидаясь расписания: вкладка
**Actions** → **Update dividend calendar** → **Run workflow**.
